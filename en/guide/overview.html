On this page

Overview ​

The Overview (/overview, "Home" on mobile) shows the status of the active Gmail account and the next useful action. It is Nid's landing page.

Header ​

"Hello {name}", followed by the account address and the backup status ("Last backup … ago" or "No backup yet").

Indicators ​

Four clickable cards (2×2 on mobile):

CardContentLeads to
Mails in Gmailnumber of mails in the account, "N unread"Mail
Recoverabletotal size of the scanned senders, "N senders to clean up" (or "Sender scan not run yet")Cleanup
NAS backupshare of Gmail mails already archived (%), number of archived mailsArchives
Active rulesnumber of active rules, "N mails processed in the last 30 days"Rules & labels

Top senders ​

The senders who send you the most mails, with "N mails · size". See all opens Cleanup.

Suggestions ​

Nid spots senders worth handling, for example:

  • "{sender}: N mails never read (size)."
  • "{sender} takes {size} with N mails."
  • "{sender} sent you N mails you rarely read."

Each suggestion offers:

  • Unsubscribe and clean up — same action as in Cleanup (disabled if the sender offers no automatic unsubscribe); progress shows on the suggestion, which goes away once the action is done;
  • Always do this — opens the rule form prefilled with the sender;
  • Ignore — hides the suggestion.

Running jobs ​

Tasks currently running, with their progress. See all opens Activity.
