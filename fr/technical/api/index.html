Référence API ​

Nid expose une API REST via Fastify. Toutes les routes sont préfixées par /api.

La documentation Swagger interactive est disponible en développement à http://localhost:4000/docs.

Authentification ​

Toutes les routes requièrent un JWT dans le cookie httpOnly token (ou un header Authorization: Bearer), sauf : /api/auth/config, /api/auth/register, /api/auth/login, /api/auth/google (+ /callback, /exchange), /api/auth/social/:provider/*, /api/auth/gmail/callback et /api/shares/public/:token. Les routes avec :accountId vérifient en plus que le compte Gmail appartient à l'utilisateur (403 sinon). Les scripts et Home Assistant utilisent un jeton d'API (Authorization: Bearer nid_…) à la place de la session.

Résumé (Home Assistant) ​

GET /api/summary 🔒 — une seule lecture légère avec tout ce qu'il faut à un tableau de bord ou à un capteur REST Home Assistant, en nombres simples. Prévu pour un jeton d'API (read suffit).

json
{
  "accounts": [{ "id", "email", "is_active", "needs_reauth", "last_backup_at", "archived_mails", "archived_bytes", "last_archived_at" }],
  "needs_reauth": 1,
  "archived_mails": 24106, "archived_bytes": 1830000000, "storage_quota_bytes": 5368709120,
  "jobs": { "active": 0, "failed_24h": 1 },
  "unread_notifications": 3
}

Home Assistant:

yaml
rest:
  - resource: https://nid.example.com/api/summary
    headers:
      Authorization: !secret nid_token   # "Bearer nid_…"
    scan_interval: 300
    sensor:
      - name: Nid comptes à reconnecter
        value_template: "{{ value_json.needs_reauth }}"
      - name: Nid mails archivés
        value_template: "{{ value_json.archived_mails }}"
      - name: Nid jobs en échec 24h
        value_template: "{{ value_json.jobs.failed_24h }}"

Pour être prévenu sans interroger, un webhook générique sur account.reauth_required peut viser un déclencheur webhook de Home Assistant (mettre WEBHOOK_ALLOW_PRIVATE_NETWORKS=true si Home Assistant est sur le réseau local).

Health check ​

GET /health

Hors préfixe /api, sans authentification. Retourne 200 si le service est opérationnel :

json
{ "status": "ok", "version": "0.1.0", "timestamp": "2026-03-20T10:00:00.000Z" }

Métriques ​

GET /api/metrics
Authorization: Bearer <METRICS_TOKEN>

Format texte Prometheus. N'existe que si METRICS_TOKEN est défini (404 sinon), 401 si le jeton est faux. Voir Production › Supervision.
